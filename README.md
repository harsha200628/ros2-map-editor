# ROS2 Map Editor 🤖🗺️

A powerful, entirely browser-based tool for editing, merging, and testing ROS/ROS2 SLAM maps. Designed specifically for roboticists to clean up raw maps, plan paths, merge multi-session scans, and define critical waypoints without relying on heavy desktop software like GIMP or Photoshop.

## Features ✨

### 🖌️ Advanced Map Editing (Core Feature)
The primary purpose of this tool is to provide a fast, intuitive way to manually edit SLAM maps exactly as the robot sees them. Say goodbye to struggling with GIMP or Photoshop!
- **Semantic Colors:** Draw directly in pure ROS semantic values to ensure your map server parses the map correctly:
  - **Free Space** (254 - White)
  - **Unknown Space** (205 - Grey)
  - **Lethal Obstacles / Walls** (0 - Black)
- **Brush, Rectangle, & Circle:** Draw freehand walls or use perfect geometric shapes to carve out new rooms or block restricted areas.
- **Polygon Tool:** Rapidly block out complex rooms or clear out entire hallways with a multi-point polygon tool. Supports open paths, closed paths, and solid fills.

### 🧹 Auto-Clean Noise
Raw SLAM maps (like those generated by slam_toolbox or gmapping) often have salt-and-pepper noise or stray pixels in open areas. 
- **Median Filter:** Instantly clean up rogue pixels with a single click while preserving sharp wall edges.

### 🗺️ A* Pathfinding Preview
Test if your robot can actually navigate your newly edited space *before* deploying it to a physical machine.
- **Costmap Inflation:** Define your robot's radius and visualize the Nav2 inflation zone dynamically.
- **Advanced A*:** The algorithm uses a closed-set MinHeap search with soft cost penalties. It actively avoids inflation zones, but will intelligently squeeze through tight hallways when it's the only available path, closely mimicking actual Nav2 behavior.
- **Smart Snapping:** If you accidentally click slightly inside a wall, the algorithm will automatically snap the start/goal points to the nearest safe free space.

### 🗺️➕🗺️ Map Merging with ICP Auto-Alignment
Combine maps from multiple mapping sessions or multiple robots into a single master map.
- **Manual Adjustments:** Drag, rotate, and flip the incoming map to get it close to your base map.
- **ICP Auto-Align:** Click "Auto-Align" to run the Iterative Closest Point (ICP) algorithm. It analyzes the geometric point clouds of both maps and mathematically snaps them together for a perfect fit.

### 📏 Measurement & Waypoints
- **Measure:** Precisely measure distances (line, path, or area) directly on the map using the real-world scale defined in your YAML.
- **Waypoints:** Place strategic points with custom headings (quaternions) and export them instantly to a JSON file for use in your autonomy stack.

### 💻 Zero-Installation UI
- Dual-sidebar layout to maximize your canvas working area.
- Runs entirely in your web browser utilizing HTML5 Canvas and JavaScript. No servers, no python dependencies, and no installations required. 
- Lightning-fast pan & zoom viewport.

## Getting Started

1. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
2. Click **Load PGM** to select your map image.
3. Click **Load YAML** to load the map metadata (resolution, origin).
4. Edit the map using the left sidebar tools.
5. Use the right sidebar to test pathfinding, apply noise filters, and view the inflation costmap.
6. Click **Export PGM + YAML** to save your updated map back to your filesystem, ready for `nav2_map_server`.

## File Structure
- `index.html`: The core UI layout.
- `style.css`: The styling, providing a beautiful dual-sidebar aesthetic with Dark/Light modes.
- `script.js`: The powerhouse containing all algorithms (A*, ICP, filtering, canvas rendering).

## Keyboard Shortcuts
- `Space + Drag` or `Middle-Mouse Drag`: Pan the map
- `Scroll`: Zoom in/out
- `Ctrl + Z`: Undo
- `Ctrl + Shift + Z`: Redo
- `D`: Select Brush tool
- `G`: Select Polygon tool
- `M`: Select Measure tool
- `R`: Select Rectangle tool
- `C`: Select Circle tool
- `W`: Select Waypoint tool
